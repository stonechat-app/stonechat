# Bundled sticker packs

`essentials/` — 512×512 transparent WebP renders of Noto Color Emoji
glyphs (https://github.com/googlefonts/noto-emoji), © Google, licensed
under the SIL Open Font License 1.1, which permits redistribution of
derived renders. Regenerate with `scripts` from the noto-emoji repo or
any CBDT-capable rasterizer at strike size 109, scaled to 512.

User-imported packs never live here — they go to the app documents
directory (`stickers/<pack>/`) on device, alongside a `recents.json`.
